Meta tags

we can add metadata to the head of our html document and this will tell the web browser what our webpage is about. Meta tags are placed within the head of the html document, not the body. Meta tags don't require closing tags.

Meta tags can take on name attributes, among others, but to start, as an example; meta name = "description" content = "a web application that provides financial insight."

Here's another example; meta name = "keywords" content = "finance, insight, education"

Could even use meta tags for something like this; meta name = "author" content = "Grant Hill"

In the event that a user is utilizing a web browser to access your web page via their own mobile device, to ensure that your webpage displays proportionately on their mobile device's screen, you could implement a meta tag which ensures that; meta name = "viewport" content = "width=device-width, initial-scale = 1.0"

we can even use meta tags to tell a web browser what sort of character encoding we're using. Although the standard doesn't necessarily require a specific encoding format, UTF-8 (also known as Unicode) is often encouraged for use by web developers (in part for security reasons). meta name = "UTF-8"

Meta can be used to instruct our webpage to refresh within a certain amount of time. meta http-equiv = "refresh" content = "30" (content, in this context, represents the number of seconds to delay before the site refreshes itself automatically)

iframes

most major websites have disabled the use of iframes, so the following instance would result in an error along the lines of, 'www.google.com refused to connect.'; iframe src = "https://google.com"

The reason why ifrmaes can be abused by hackers and can consequently pose such a danger is because they can change the size of their embed website to reflect the same size as yours; thus posing as your website. This is especially catastrophic in the event of otherwise trusted websites that require or ask for your personal information, say a bank, or other financial institution.... and and so if you as a user go to that trusted site addresss, and enter into it your personal information; unknowingly doing this for a potential embed site that's posing as the site you thought you were going to, that embed site can still capture your personal information.

There are still some major websites that do accept the use of iframes, such as bing.com. iframe src = "https://bing.com" and this will feature a small window of the bing website popping up on your webpage. To change its window size when does pop up on your webpage, you could write something like this; iframe src = "https://bing.com" width = "700" height = "400" and then that same iframe of bing.com would become much larger on your webpage.
